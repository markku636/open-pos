# 出事的時候怎麼辦

> 這一頁是給**店裡的人**看的，不是給工程師看的。
> 建議印出來貼在收銀機旁邊。

---

## 先做這件事：繼續做生意

系統壞掉的時候，**先拿紙筆繼續收錢**。修系統可以等，客人不能等。

* 手寫單：品名、數量、金額、收了多少、找了多少
* 廚房用喊的或用手寫單
* 把手寫單依序編號，之後補登用得到

系統恢復之後，那些手寫單要一張一張補登進去（開單 → 點餐 → 結帳）。
補登的時候在備註寫「補登 手寫單 #12」，之後對帳才知道那是怎麼來的。

## 症狀 1：程式打不開

### 畫面上有訊息

**照著訊息做。** 這個系統的錯誤訊息都會說出下一步該做什麼，例如：

* 「已經有一個 open-pos 在執行」→ 看一下工作列，它可能只是被縮到背景了
* 「資料不能放在網路磁碟」→ 把資料夾搬回這台電腦的硬碟上
* 「這份資料是比較新的 open-pos 建立的」→ 去下載新版

### 什麼都沒有，點兩下沒反應

1. 重新開機一次。
2. 還是不行 → 跳到**症狀 3：從備份還原**。

---

## 症狀 2：印不出來

先看畫面右上角**有沒有紅點**。有的話點下去，它會說是哪一台、為什麼。

| 上面寫的 | 怎麼辦 |
| --- | --- |
| 「一直連不上」 | 檢查印表機電源與網路線；重開印表機再按「補印」 |
| 「需要有人到機器旁邊處理」 | 換紙、關好蓋子，然後按「補印」 |
| 「設定可能有問題」 | 到「出單機」頁按「測試連線」→「測試列印」 |
| 「還沒有設定任何出單機」 | 到「出單機」頁新增一台（IP + 連接埠 9100） |

**印出來是亂碼**：到「出單機」頁把「中文編碼」換一個（Big5 ↔ GB18030），
按「測試列印」。台灣賣的機器多半是 Big5。

單子**沒有消失**：它們在佇列裡等，機器修好之後會自己印出來
（超過 30 分鐘的會被標成「印不出來」，可以按補印）。

## 症狀 3：從備份還原

**還原不會刪掉現在的資料。** 現在的資料會被改名保留，事後還救得回來。

1. 開 open-pos → **備份**頁
2. 在清單裡挑一份 —— 檔名上有日期時間，挑**出事之前**最近的那一份
3. 按「還原」→ 確認
4. **關掉 open-pos，再重新打開**（還原在啟動時才會完成）

還原之後，從那個時間點到現在的單會不見。用手寫單補登回去。

### 如果連程式都打不開

1. 找到資料夾（預設在 `C:\Users\<你的帳號>\AppData\Roaming\open-pos\`）
2. 把 `data\pos.db`、`pos.db-wal`、`pos.db-shm` 三個檔**改名**
   （例如加上 `.bad`），不要刪除
3. 從 `backups\` 或你的隨身碟裡挑一份備份，複製到 `data\` 並改名成 `pos.db`
4. 打開 open-pos

> 這一段有點技術性。如果不確定，**先不要動**，把整個資料夾複製一份到隨身碟上
> 再找人幫忙 —— 複製一份的成本是零，弄壞的成本是一天的營業額。

## 症狀 4：主機整台壞了

這個系統是單機架構：**第二台是冷備，不是即時備援**。

1. 在第二台電腦裝 open-pos（第一次就要先裝好，不要等出事才裝）
2. 插上備份用的隨身碟
3. 開 open-pos → 備份頁 → 挑最新的一份 → 還原 → 重開
4. 把出單機的網路線接過來（或在設定頁改 IP）

大約十分鐘可以繼續營業，會少掉「最後一次備份到現在」之間的單。
那些用手寫單補登。

## 症狀 5：平板 / 手機連不上

1. 平板跟收銀機是**同一個 Wi-Fi** 嗎？
2. 收銀機的 IP 變了嗎？（路由器重開之後很常見）
   → 收銀機啟動時會印出正確網址，照著重新輸入
3. Windows 防火牆有沒有跳出過對話框、而你按了「取消」？
   → 到「系統狀態」頁看區網服務有沒有起來

**根治**：請網路的人在路由器上幫收銀機設**固定 IP 或 DHCP 保留**。
不然每次路由器重開，桌卡上的 QR 就全部失效。

---

## 要回報問題的時候

1. 開 open-pos → **系統狀態** → 「產生診斷資訊」→「複製全部」
2. 到 <https://github.com/markku636/open-pos/issues/new> 貼上去
3. 說一下發生了什麼、大概幾點

診斷資訊裡**沒有**品名、客人資訊或帳單明細，可以放心貼。
系統也不會自動上傳任何東西。

---

## 平常就該做的三件事

1. **備份的隨身碟一直插著。** 到「備份」頁確認「第二個備份位置」有設。
   跟資料庫同一顆硬碟的備份，硬碟壞掉時會一起死。
2. **買一台不斷電系統（UPS）。** 一千元的 UPS 比這個系統裡任何一行程式碼
   都更能避免資料損壞。
3. **每個月自己按一次「還原」試試看。** 沒有人確認過的備份不算備份。
   （測試時可以在第二台電腦上做。）
